Godot 4.7 / 正式 Gua 1.1.2 で、会話・仕入れ・売却・依頼受注・部分納品・報酬受領の通常操作から3件完了、結果、再プレイへ進む Windows 用ゲームを追加します。日数は翌日ボタンだけで進み、受注前仕入れ、期限、鞄・在庫・所持金の制約を処理します。日本語／英語、画面サイズ、ポーズ、セーブ／ロード、リセットと3種の個別不具合フラグを備えます。
